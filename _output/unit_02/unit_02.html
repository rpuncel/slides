Part 1: Introducing Random Variables

What Is a Random Variable?

Intuition:

  • A model for where the numbers in data come from.
  • Like a regular variable but with uncertainty about its value (with some probability of taking on different values).

Definition:

Given probability space \((\Omega, S, P)\), a random variable is a measurable function from \(\Omega\) to \(\mathbb{R}\).

  • A Random Variable is the fundamental building block of a statistical model, but what is it?
  • Intuitively, we’re used to variables in our datasets. They have one value. But as statisticians, we need a way to model variables acknowledging that different values are possible.
  • Finally, we have the formal definition that you’ll see in your textbook. A random variable is a function from a probability space to \(\mathbb{R}\). This one, unfortunately, leaves students scratching their heads. It doesn’t seem to capture the intuition.

What Is a Random Variable (Formally)?

  • I’m going to try to make the formal definition make more sense. And I’ll do it by telling a very stylized story about how a variable gets the value it has.
  • This story is about something I do in my spare time, which is roast coffee. It has three characters.
  • The first character is my coffee roaster. This is in the actual real world. It has some state: the atoms are moving with some velocity, the proteins in the beans are in some configuration - hopefully the proteins aren’t burnt.
  • Because I’m serious about my roasting, I want some data. So the second character is this thermometer. It represents measurement or observation. Think of the state of the roaster as an input to the thermometer.
  • The final character is the output of the thermometer: a regular old variable. 160 degrees.

What Is a Random Variable (Formally)?

  • Now as statisticians, we think that there must be some randomness in that number. In other words, if you could magically rewind time and start roasting again, you might get a different number.
  • You might not actually believe this - if we could recreate the start of the experiment EXACTLY, down to the location of atoms, maybe you think you’d get the same number. But at least as statisticians, we want a model for how this number was created that involves randomness. Here’s how we do it…
  • First, we need a probability space. Each outcome in this space represents one possible state of my coffee roaster. There is a probability function that tells you how probable different states are.
  • Next, we have the random variable. This is like the thermometer, but it doesn’t give us a single number. It’s a function that takes in any outcome - any state of the coffee roaster.
  • Finally, the last character is the real numbers. The random variable is a function from \(\Omega\) to the reals.

What Is a Random Variable (Formally)?

  • That’s the setup. Let’s see what happens when the experiment runs.
  • First, nature reaches in and selects one possible outcome. Remember this represents one possible arrangement of all the atoms in my roaster.
  • Use annotation, label outcome \(\omega\), draw arrow to \(T\), draw another arrow to 160.

What Is a Random Variable (Formally)?

  • Next, the thermometer (our random variable) does its thing. It takes the state of the roaster - the outcome \(\omega\) - and transforms it into a temperature reading.
  • But wait, instead of a single reading, we get a range of possible readings, each with a different probability. This is the randomness we were talking about.
  • The random variable \(T\) maps the outcome \(\omega\) to this range of temperatures. It’s not just a simple function anymore; it’s a function that accounts for uncertainty.

What Is a Random Variable (Formally)?

  • Finally, we take a look at the probability distribution of our random variable.
  • This distribution tells us the likelihood of each possible temperature reading.
  • It’s like a map that shows us the landscape of possibilities for our random variable, \(T\).
  • And that’s the formal definition of a random variable. It’s a function that not only depends on the outcome of a random process but also has a probability distribution that describes its behavior.

Part 2: Joint Distributions

What Is a Joint Distribution?

Intuition:

  • A model for the relationship between two or more random variables.
  • Like a regular distribution but for multiple variables, showing how they co-vary.

Definition:

Given a probability space and two random variables \(X\) and \(Y\) defined on that space, the joint distribution of \(X\) and \(Y\) is the probability distribution of the random vector \((X, Y)\).

  • Just as random variables are the building blocks of statistical models, joint distributions allow us to model and understand the relationships between multiple random variables.
  • Intuitively, if random variables are like single notes in a musical piece, joint distributions are like chords - they show how notes combine and interact.
  • Formally, the joint distribution is defined for a pair of random variables, but the concept extends to more variables. It’s the probability distribution of the random vector formed by these variables.

What Is a Joint Distribution (Formally)?

  • Let’s break down the formal definition of joint distribution using a similar story.
  • Imagine we have two coffee roasters this time, each with its own set of atoms and proteins. We’ll call them Roaster 1 and Roaster 2.
  • Just like before, we have a thermometer for each roaster. But now, we’re interested in how the readings from both thermometers relate to each other.
  • The joint distribution will help us understand the relationship between the temperatures \(T_1\) and \(T_2\) from Roaster 1 and Roaster 2, respectively.

What Is a Joint Distribution (Formally)?

  • First, we define a new probability space that covers all possible outcomes for both roasters.
  • Each outcome in this space represents a possible state for both Roaster 1 and Roaster 2.
  • Just like before, we have a probability function that tells us how probable different states are, but now it’s for the combined system of both roasters.

What Is a Joint Distribution (Formally)?

  • Next, we have our random variables for each roaster, \(T_1\) and \(T_2\).
  • These random variables are like the thermometers from before, but now we have one for each roaster.
  • They take in the outcomes - the states of Roaster 1 and Roaster 2 - and transform them into temperature readings.
  • But remember, these readings come from a joint distribution, so they are not independent. The reading from one thermometer gives us information about the reading from the other.

What Is a Joint Distribution (Formally)?

  • Finally, we look at the joint probability distribution of our random variables.
  • This distribution tells us the likelihood of each possible pair of temperature readings \((T_1, T_2)\).
  • It’s like a map that shows us the landscape of possibilities for our random variables, \(T_1\) and \(T_2\), and how they are related.
  • And that’s the formal definition of a joint distribution. It’s a probability distribution that covers multiple random variables, showing us the relationships and dependencies between them.

Conclusion

  • This week, we covered the basics of random variables and joint distributions.
  • We started with the intuition behind random variables as models for uncertainty in our data.
  • Then, we moved on to the formal definition of random variables and how they are used to describe random processes.
  • After that, we explored joint distributions, which allow us to model and understand the relationships between multiple random variables.
  • Finally, we looked at the formal definition of joint distributions and how they extend the concept of random variables to multiple dimensions.
